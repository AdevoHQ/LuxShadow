# LuxShadow 🌘

A lightweight and minimalist web utility for generating CSS box-shadows in real time. Designed as a single self-contained file for maximum portability.

## Features

* **Real-Time Sliders:** Smooth controls for X-axis, Y-axis, Blur, and Spread.
* **Dynamic Color Picker:** Color selection with built-in opacity adjustment.
* **Inset Switch:** Toggle option for inner shadows (`inset`).
* **Border Radius:** Live preview box-radius adjustment.
* **One-Click Copy:** Instantly copy the generated CSS code to your clipboard with a single click.

## Usage

Simply open `index.html` in any web browser. Zero dependencies, no installations or local server configurations required.
