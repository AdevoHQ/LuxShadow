# LuxShadow 🌘

Utilidad web ultraligera y minimalista para generar sombras CSS (`box-shadow`) en tiempo real. Diseñada en un solo archivo autocontenido para máxima portabilidad.

## Características
* Controles deslizantes en tiempo real para Eje X, Eje Y, Difuminado (Blur) y Expansión (Spread).
* Selector de color dinámico con ajuste de opacidad.
* Interruptor para sombras interiores (`inset`).
* Ajuste de radio de bordes (`border-radius`) en la caja de previsualización.
* Copia automática del código CSS al portapapeles con un clic.

## Uso
Simplemente abre el archivo `index.html` en cualquier navegador web. Cero dependencias, sin instalaciones ni configuraciones de servidores locales.
